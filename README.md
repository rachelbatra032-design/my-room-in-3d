# My Room in 3D

A room you can orbit, zoom, and click. Inspired by [Bruno Simon’s my-room-in-3d](https://github.com/brunosimon/my-room-in-3d). Hosted on GitHub Pages, not Vercel.

Live: https://rachelbatra032-design.github.io/my-room-in-3d/

This pass is a low-poly stand-in of my room from photos: desk wall, window corner with shelves, bed, and the photo board. A later pass can replace the boxes with a Blender model.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Vite writes static files to `dist/`. GitHub Actions publishes that folder to Pages on every push to `main`.

## Controls

- Drag to orbit
- Scroll to zoom
- Click the laptop to toggle the screen
